# まなびより Design Notes

## 目的

まなびよりは、仕事・暮らし・人との関わりから生まれた気づきや学びを、安心して残し、振り返って次の行動へつなげるアプリです。

## 今回のUI方針

- 初見の人が「全部を埋めないといけない」と感じないことを優先する。
- メモ登録では、基本情報、出来事、気づき、次の行動を主導線にする。
- 思考の途中経過、価値観、AI/Dラボ、成功ジャーナル、強みフィードバックは、必要なときだけ開ける補助セクションとして扱う。
- 種別には、失敗や教訓だけでなく、前向きな探索を残せる「好奇心」を含める。
- 色と余白は既存テーマを使い、安心して内省できる落ち着いた印象を保つ。

## 受け入れ条件

- スマートフォン幅でフォーム項目が長くなりすぎず、主要項目へすぐ到達できる。
- 任意セクションは折りたたみで隠せるが、編集時に既存入力がある場合は確認できる。
- 「好奇心」が登録、一覧、詳細、振り返り集計で同じ種別として扱われる。
- アイコンはアプリ名と雰囲気に合い、Expo Web / ネイティブ設定から参照される。
