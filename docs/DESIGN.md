# まなびより Design Notes

## 目的

まなびよりは、仕事・暮らし・人との関わりから生まれた気づきや学びを、安心して残し、振り返って次の行動へつなげるアプリです。

## 今回のUI方針

- 初見の人が「全部を埋めないといけない」と感じないことを優先する。
- メモ登録では、基本情報、出来事、気づき、次の行動を主導線にする。
- 思考の途中経過、価値観、AI/Dラボ、成功ジャーナル、強みフィードバックは、必要なときだけ開ける補助セクションとして扱う。
- 種別には、失敗や教訓だけでなく、前向きな探索を残せる「好奇心」を含める。
- 色と余白は既存テーマを使い、安心して内省できる落ち着いた印象を保つ。

## 2026-08-17 品質改善ループ

### 対象ユーザーと主要タスク

- Supabaseの一時停止や通信不良の後でも、状況と次の操作を迷わず理解できること。
- 初回利用者がメールアドレスとパスワードを誤りなく入力し、ログイン・新規登録・再設定へ進めること。
- 既存利用者が、追加済みの「好奇心」や補助メモ項目を含めて過去の記録を探せること。

### 採用する改善

- ログイン入力には常時見えるラベルを付け、パスワード表示切替、処理中表示、エラーのライブ通知を用意する。
- 320px級の小画面やソフトウェアキーボード表示時にも操作できるよう、認証画面を縦スクロール可能にする。
- Supabase接続エラーを成功色で表示せず、原因の概要と再試行操作を示す。
- メモ検索では、タイトル・主要本文だけでなく、応援メモ、成功ジャーナル、強みフィードバック、AI/Dラボ、価値観、タグも検索対象にする。
- メモ種別フィルターへ「好奇心」を含め、検索0件とデータ0件を別の状態として扱う。
- ナビゲーションとフィルターの現在位置を、色だけでなくアクセシビリティ状態でも伝える。

### レスポンシブ・アクセシビリティ

- 320x568、390x844、1280x800を代表サイズとして確認する。
- 入力ラベル、フォーカス表示、44px以上の操作領域、キーボード操作、処理中・選択中の支援技術向け状態を確認する。
- 文字や要素の重なり、意図しない横スクロール、短い縦画面での操作不能を残さない。

### 今回実装しない範囲

- Supabaseのスキーマ変更、認証方式の変更、オフライン同期、新しい外部サービスの導入。
- 未認証のままデータ画面へ入るプレビューモード。
- コミット、プッシュ、デプロイ、公開設定の変更。

## 受け入れ条件

- スマートフォン幅でフォーム項目が長くなりすぎず、主要項目へすぐ到達できる。
- 任意セクションは折りたたみで隠せるが、編集時に既存入力がある場合は確認できる。
- 「好奇心」が登録、一覧、詳細、振り返り集計で同じ種別として扱われる。
- アイコンはアプリ名と雰囲気に合い、Expo Web / ネイティブ設定から参照される。
- Supabaseへ接続できない場合、エラー状態と再試行操作が成功状態と区別して表示される。
- 認証入力はプレースホルダーだけに依存せず、短いスマートフォン画面でも最後の操作まで到達できる。
- 検索条件に一致しない状態と、保存データが1件もない状態で、それぞれ次の行動が分かる。
